# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

### How to Report

1. **Do NOT** open a public GitHub issue for security vulnerabilities
2. Email security concerns to: [security@example.com]
3. Include the following information:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

### What to Expect

- **Acknowledgment**: We will acknowledge receipt within 48 hours
- **Assessment**: We will assess the vulnerability within 7 days
- **Resolution**: We will work on a fix and coordinate disclosure
- **Credit**: We will credit you in the fix announcement (unless you prefer anonymity)

## Security Best Practices for Users

When using prompts from this collection:

1. **Never include sensitive data** in prompts (passwords, API keys, personal information)
2. **Review prompts** before using them in production environments
3. **Be aware of prompt injection risks** when using prompts in automated systems
4. **Validate AI outputs** before acting on them, especially for code and business decisions

## Scope

This security policy applies to the prompts and code in this repository. It does not cover:

- Third-party AI models or services
- External links referenced in prompts
- User-generated modifications to prompts

Thank you for helping keep Awesome Prompts safe and secure! 🔒
