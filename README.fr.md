## 🤔 Pourquoi Awesome Prompts ?

### Avant (Prompt vague) ❌

```
帮我写个代码审查
```

### Après (Prompt précis) ✅

```
Vous êtes un ingénieur en sécurité senior. Effectuez un audit de sécurité OWASP Top 10 du code suivant.

Langage : Python
Framework : Django
Code :
[paste your code]

Veuillez produire la sortie selon le format suivant :
1. 🔴 Vulnérabilités critiques (Critical)
2. 🟠 Vulnérabilités élevées (High)
3. 🟡 Vulnérabilités moyennes (Medium)
4. 🔵 Vulnérabilités faibles (Low)

Chaque problème doit inclure : description, niveau de risque, scénario d'attaque, recommandations de correction (avec exemples de code)
```

**Résultat : une sortie 10 fois meilleure. À chaque fois.**

## 🚀 Démarrage rapide

### 1. Parcourir

Choisissez une catégorie ci-dessus et trouvez le prompt adapté à vos besoins.

### 2. Copier

Copiez le modèle de prompt et remplacez `[VARIABLES]` par vos informations spécifiques.

### 3. Coller et obtenir des résultats

Collez dans votre outil IA préféré (ChatGPT, Claude, Gemini, etc.) et obtenez des résultats de haute qualité.

## 📖 Guide d'utilisation

### Variables

Tous les prompts utilisent des `[VARIABLES]` que vous devez remplacer :

```
[TOPIC]       → votre sujet spécifique
[LANGUAGE]    → votre langage de programmation
[AUDIENCE]    → votre public cible
[CODE]        → votre code réel
```

### Conseils

1. **Soyez précis** : Plus vous fournissez de contexte, meilleure sera la sortie.

2. **Itérez** : Utilisez la première sortie comme point de départ, puis affinez.

3. **Combinez** : Mélangez des prompts de différentes catégories pour des tâches complexes.

4. **Personnalisez** : Modifiez les prompts pour correspondre à votre flux de travail et votre style.
