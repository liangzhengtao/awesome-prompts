## [1.0.0] - 2024-01-01

### Added

#### 编程开发 / Programming (4 files, 64+ prompts)
- `code-review.md` - Security audit, performance review, readability check, architecture review
- `debugging.md` - Error analysis, stack trace interpretation, root cause analysis
- `refactoring.md` - Extract method, simplify conditionals, improve naming, reduce complexity
- `documentation.md` - README generation, API docs, code comments, changelog

#### 内容创作 / Content Creation (3 files, 50+ prompts)
- `blog-writing.md` - Outline generation, intro hooks, SEO optimization, conclusion crafting
- `social-media.md` - Twitter threads, LinkedIn posts, Instagram captions, TikTok scripts
- `email-sequences.md` - Welcome series, nurture sequences, sales emails, re-engagement

#### 商业办公 / Business (3 files, 48+ prompts)
- `business-strategy.md` - SWOT analysis, competitive analysis, market research, business model canvas
- `presentation.md` - Slide content, speaker notes, Q&A preparation, storytelling
- `project-management.md` - Requirements gathering, risk assessment, status reports, retrospectives

#### 学习教育 / Education (3 files, 50+ prompts)
- `study-assistant.md` - Concept explanation, flashcard generation, quiz creation, study plans
- `teaching.md` - Lesson plans, rubric creation, student feedback, curriculum design
- `research.md` - Literature review, hypothesis generation, methodology design, data analysis

#### 创意设计 / Creative Design (2 files, 35+ prompts)
- `image-generation.md` - Style modifiers, composition keywords, quality boosters, negative prompts (20+ templates)
- `creative-writing.md` - Story starters, character creation, world building, dialogue generation (15+ templates)

#### Community Files
- `README.md` - Bilingual documentation with quick start guide
- `CONTRIBUTING.md` - Contribution guidelines
- `CODE_OF_CONDUCT.md` - Community code of conduct
- `SECURITY.md` - Security policy
- `CHANGELOG.md` - This file

- `.github/` - Issue templates, PR template, CI workflow
