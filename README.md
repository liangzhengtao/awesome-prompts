## 🤔 Why Awesome Prompts?

### Before (模糊的 Prompt) ❌

```
帮我写个代码审查
```

### After (精确的 Prompt) ✅

```
你是一位资深安全工程师，请对以下代码进行 OWASP Top 10 安全审查。

语言：Python
框架：Django
代码：
[paste your code]

请按以下格式输出：
1. 🔴 严重漏洞（Critical）
2. 🟠 高危漏洞（High）
3. 🟡 中危漏洞（Medium）
4. 🔵 低危漏洞（Low）

每个问题请包含：问题描述、风险等级、攻击场景、修复建议（含代码示例）
```

**Result: 10x better output. Every time.**
**结果：每次都能获得 10 倍更好的输出。**

## 🚀 Quick Start / 快速开始

### 1. Browse / 浏览

Choose a category above and find the prompt that fits your needs.
选择上面的分类，找到适合你需求的 Prompt。

### 2. Copy / 复制

Copy the prompt template and replace `[VARIABLES]` with your specific information.
复制 Prompt 模板，将 `[VARIABLES]` 替换为你的具体信息。

### 3. Paste & Get Results / 粘贴即见效

Paste into your favorite AI tool (ChatGPT, Claude, Gemini, etc.) and get high-quality results.
粘贴到你喜欢的 AI 工具中（ChatGPT、Claude、Gemini 等），获取高质量结果。

## 📖 How to Use / 使用指南

### Variables / 变量

All prompts use `[VARIABLES]` that you need to replace:
所有 Prompt 使用 `[VARIABLES]`，你需要替换它们：

```
[TOPIC]       → your specific topic / 你的具体主题
[LANGUAGE]    → your programming language / 你的编程语言
[AUDIENCE]    → your target audience / 你的目标受众
[CODE]        → your actual code / 你的实际代码
```

### Tips / 技巧

1. **Be specific / 具体化**: The more context you provide, the better the output.
   提供的上下文越多，输出越好。

2. **Iterate / 迭代**: Use the first output as a starting point, then refine.
   将第一次输出作为起点，然后优化。

3. **Combine / 组合**: Mix prompts from different categories for complex tasks.
   组合不同分类的 Prompt 来完成复杂任务。

4. **Customize / 定制**: Modify the prompts to fit your workflow and style.
   修改 Prompt 以适配你的工作流程和风格。
