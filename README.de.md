## 🤔 Warum Awesome Prompts?

### Vorher (Vager Prompt) ❌

```
Schreib mir eine Code-Review
```

### Nachher (Präziser Prompt) ✅

```
Du bist ein Senior Security Engineer. Führe ein OWASP Top 10 Security Audit für den folgenden Code durch.

Sprache: Python
Framework: Django
Code:
[Code einfügen]

Bitte im folgenden Format ausgeben:
1. 🔴 Kritische Schwachstellen
2. 🟠 Hohe Schwachstellen
3. 🟡 Mittlere Schwachstellen
4. 🔵 Niedrige Schwachstellen

Jedes Problem muss enthalten: Beschreibung, Risikostufe, Angriffsszenario, Korrekturvorschlag (mit Codebeispiel)
```

**Ergebnis: 10x besserer Output. Jedes Mal.**

## 🚀 Schnellstart

### 1. Stöbern

Wählen Sie eine Kategorie oben und finden Sie den passenden Prompt.

### 2. Kopieren

Kopieren Sie das Prompt-Template und ersetzen Sie `[VARIABLES]` mit Ihren spezifischen Informationen.

### 3. Einfügen & Ergebnisse erhalten

Fügen Sie es in Ihr bevorzugtes KI-Tool (ChatGPT, Claude, Gemini etc.) ein und erhalten Sie hochwertige Ergebnisse.

---

## 📖 Verwendung

### Variablen

Alle Prompts verwenden `[VARIABLES]`, die Sie ersetzen müssen:

```
[TOPIC]       → Ihr spezifisches Thema
[LANGUAGE]    → Ihre Programmiersprache
[AUDIENCE]    → Ihre Zielgruppe
[CODE]        → Ihr tatsächlicher Code
```

### Tipps

1. **Seien Sie spezifisch**: Je mehr Kontext Sie liefern, desto besser der Output.

2. **Iterieren**: Nutzen Sie den ersten Output als Ausgangspunkt, dann verfeinern Sie.

3. **Kombinieren**: Mischen Sie Prompts aus verschiedenen Kategorien für komplexe Aufgaben.

4. **Anpassen**: Passen Sie die Prompts an Ihren Workflow und Stil an.
