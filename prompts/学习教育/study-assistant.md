## 概念解释 / Concept Explanation

### 1. 费曼学习法解释

```
请用费曼学习法（Feynman Technique）解释以下概念。

概念：[CONCEPT]
学科领域：[SUBJECT]
我的当前水平：[LEVEL]（初学者/中级/高级）

要求：
1. 用 12 岁小孩能听懂的语言解释核心概念
2. 用一个日常生活中的类比来说明
3. 指出常见的误解
4. 逐步深入：从直觉理解 → 正式定义 → 数学/逻辑表达
5. 最后用专业语言重新定义

如果解释中出现了专业术语，请在首次出现时用括号解释。
```

### 2. 多角度概念解释

```
请从 5 个不同角度解释以下概念。

概念：[CONCEPT]
学科：[SUBJECT]

5 个角度：
1. 📖 教科书定义（正式、准确）
2. 🎯 一句话概括（精华版）
3. 🌍 类比解释（用日常事物类比）
4. 📊 图示解释（用文字描述一个图表/示意图）
5. 💻 代码/公式解释（如果是技术/数学概念）

最后给出 3 个实际应用场景，帮助理解概念的用途。
```

### 3. 概念关联图

```
帮我梳理以下概念之间的关系。

主题：[TOPIC]
核心概念列表：[CONCEPTS]

请生成：
1. 概念层次结构（哪些是基础概念，哪些是进阶概念）
2. 概念间的依赖关系（学 A 之前需要先学 B）
3. 概念间的相似和对比
4. 推荐的学习顺序
5. 每个概念的一句话定义
6. 用文字描述概念关系图的结构
```

### 4. 知识点深度解析

```
深度解析以下知识点，我要参加 [EXAM/INTERVIEW]。

知识点：[KNOWLEDGE_POINT]
考试/面试类型：[EXAM_TYPE]
已掌握程度：[CURRENT_LEVEL]（不了解/了解基础/较熟悉）

请提供：
1. 核心概念（必须掌握的内容）
2. 常见考法（选择题/简答题/编程题等）
3. 高频考点和易错点
4. 与相关知识点的联系
5. 记忆口诀/助记方法
6. 3 道由浅入深的练习题（含答案和解析）
```

### 5. 学科交叉解释

```
从多个学科的角度解释以下主题。

主题：[TOPIC]
涉及学科：[SUBJECTS]（如数学、物理、计算机科学、经济学等）

对每个学科的角度：
1. 该学科如何定义这个主题
2. 该学科的核心工具/方法
3. 实际应用案例
4. 与其他学科视角的联系

最后总结：为什么跨学科理解对深入掌握这个主题很重要。
```

## 闪卡生成 / Flashcard Generation

### 6. 知识点闪卡批量生成

```
将以下学习材料转化为闪卡（Flashcards）。

学习材料：
```[MATERIAL]```

学科：[SUBJECT]
闪卡数量：[NUMBER] 张

闪卡格式：
---
**正面：** [问题/概念]
**背面：** [答案/解释]
**标签：** [主题标签]
**难度：** ⭐/⭐⭐/⭐⭐⭐
**助记：** [记忆技巧]（可选）
---

要求：
- 问题清晰具体，避免模糊
- 答案简洁但完整
- 按主题分组
- 包含记忆技巧（谐音/联想/口诀）
- 标注重点和高频考点卡
```

### 7. 间隔重复学习计划

```
为以下闪卡制定间隔重复学习计划。

闪卡内容：[FLASHCARDS]
学习周期：[DAYS] 天
每天可用学习时间：[MINUTES] 分钟
当前掌握情况：[MASTERY_LEVEL]

输出格式：
| 天数 | 复习旧卡 | 新卡 | 预计时间 | 学习策略 |

间隔重复策略（基于 SM-2 算法简化版）：
- 第 1 天：学习
- 第 2 天：第一次复习
- 第 4 天：第二次复习
- 第 7 天：第三次复习
- 第 14 天：第四次复习
- 第 30 天：第五次复习

根据掌握程度调整间隔。
```

```
**对比闪卡背面：**

额外生成 2-3 张应用型闪卡，测试是否真正理解了区别。
```

## 测验创建 / Quiz Creation

### 9. 选择题测验

```
基于以下学习材料创建选择题测验。

学习材料：
```[MATERIAL]```

题目数量：[NUMBER] 题
难度分布：[DIFFICULTY]（如"30% 简单 + 50% 中等 + 20% 困难"）
题型：[TYPE]（单选/多选/混合）

每题格式：
**Q[编号]:** [题目]
A) [选项A]
B) [选项B]
C) [选项C]
D) [选项D]

**答案：** [正确选项]
**解析：** [为什么对/为什么错]
**知识点：** [对应的知识点]
**难度：** 简单/中等/困难

要求：
- 干扰项要合理（不能太明显错误）
- 避免"以上都是"这类选项
- 题目表述清晰无歧义
```

### 10. 编程/实操测验

```
为以下编程/实操主题创建实践测验。

主题：[TOPIC]
编程语言：[LANGUAGE]
难度：[DIFFICULTY]

测验结构：
1. 基础题（2 题）- 测试基本概念理解
2. 应用题（2 题）- 测试实际运用能力
3. 综合题（1 题）- 测试综合运用能力

每题包含：
- 题目描述
- 输入/输出示例
- 提示（不直接给答案）
- 参考答案
- 评分标准
- 常见错误
```

### 11. 主观题/论述题

```
基于以下学习材料创建主观题测验。

学习材料：
```[MATERIAL]```

题目数量：[NUMBER] 题

每题包含：
- 题目（开放式问题）
- 考查要点（评分时关注什么）
- 参考答案框架（不是标准答案，是答题框架）
- 评分标准（满分 [SCORE] 分的分配）
- 高分答案特点
- 常见失分点
```

### 12. 自我评估问卷

```
为以下学科/技能创建自我评估问卷。

学科/技能：[SUBJECT]
评估维度：[DIMENSIONS]（如理论/实践/应用等）

问卷格式：
| 编号 | 评估项 | 评分(1-5) | 备注 |
|------|--------|-----------|------|

评分标准说明：
- 1 分：完全不了解
- 2 分：听说过但不理解
- 3 分：理解基本概念
- 4 分：能独立应用
- 5 分：能教给别人

评估后输出：
1. 雷达图数据（各维度得分）
2. 优势和短板分析
3. 个性化学习建议
4. 推荐学习资源
```

### 15. 30 天挑战计划

```
为以下学习目标设计 30 天挑战计划。

学习目标：[GOAL]
每天可用时间：[DAILY_MINUTES] 分钟

| 天数 | 主题 | 学习内容 | 实践任务 | 完成标志 |
```

## 笔记整理 / Note Taking

### 17. 康奈尔笔记法

```
将以下学习材料整理为康奈尔笔记格式。

学习材料：
```[MATERIAL]```

康奈尔笔记格式：
| 笔记栏（右侧 70%） | 提示栏（左侧 30%） |
|---------------------|---------------------|
| 详细笔记内容 | 关键词/问题 |
| ... | ... |
| ... | ... |

底部：总结（3-5 句话概括本页要点）

要求：
- 笔记用简洁的要点格式
- 提示栏用问题形式（便于复习时自测）
- 总结用自己的话概括
```

## 💡 使用技巧 / Tips

1. **告知水平**：告诉 AI 你的当前水平，解释的深度会更合适
2. **指定考试**：如果有具体考试（如考研/CPA/雅思），AI 会更针对性地出题
3. **要求自测**：让 AI 生成自测题，检验学习效果
4. **间隔复习**：让 AI 按间隔重复的原则安排复习
5. **输出格式**：如果使用 Anki 等工具，要求特定格式的输出

## ⚠️ 常见错误 / Common Mistakes

- ❌ 被动学习（只看不练），应该要求 AI 生成练习题
- ❌ 一次性学太多，应该分阶段、有节奏
- ❌ 不复习，学习曲线会急剧下降
- ❌ 只背不理解，应该要求 AI 用多种方式解释
- ❌ 不做总结，学完一个主题应该让 AI 帮你总结
