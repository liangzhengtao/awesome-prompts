## 教案设计 / Lesson Plans

### 1. 标准教案生成

```
为以下课程主题设计一份完整教案。

课程主题：[TOPIC]
学科：[SUBJECT]
年级/学生水平：[GRADE_LEVEL]
课时长度：[DURATION] 分钟
班级规模：[CLASS_SIZE]

教案格式：
## 📋 教案：[课题名称]

### 教学目标
- 知识目标：学生将学会...
- 能力目标：学生将能够...
- 情感目标：学生将体会/认识到...

### 教学重点与难点
- 重点：[必须掌握的内容]
- 难点：[容易混淆/难以理解的内容]
- 突破策略：[如何帮助学生理解难点]

### 教学准备
- 教师准备：[教具/PPT/材料]
- 学生准备：[预习要求]

### 教学过程
| 环节 | 时间 | 教学活动 | 学生活动 | 设计意图 |
|------|------|----------|----------|----------|
| 导入 | 5min | ... | ... | ... |
| 新授 | 20min | ... | ... | ... |
| 练习 | 10min | ... | ... | ... |
| 总结 | 5min | ... | ... | ... |

### 板书设计
[板书结构]

### 作业设计
- 基础题：[所有学生完成]
- 提高题：[学有余力的学生]
- 拓展题：[感兴趣的学生]

### 教学反思（课后填写）
[反思模板]
```

### 2. 互动式教案

```
设计一堂高度互动的课程教案。

主题：[TOPIC]
学生年龄段：[AGE_GROUP]
教学目标：[OBJECTIVES]
可用资源：[RESOURCES]

互动设计要求：
- 每 10-15 分钟切换一次活动形式
- 至少包含 3 种互动形式（讨论/小组/游戏/角色扮演等）
- 设计"全员参与"机制（确保每个学生都参与）
- 包含即时反馈环节
- 包含课堂管理策略

输出互动流程图和详细活动说明。
```

### 3. 差异化教学教案

```
设计一份满足不同学习水平学生的差异化教案。

主题：[TOPIC]
班级情况：[CLASS_INFO]（如"学生水平参差不齐，约 30% 超前，50% 正常，20% 落后"）

差异化策略：
1. 内容差异化（不同难度的学习材料）
2. 过程差异化（不同方式的学习活动）
3. 产出差异化（不同难度的作业/考核）

对每个层次的学生：
- 🔵 基础层：[学习目标 + 活动 + 支持]
- 🟢 标准层：[学习目标 + 活动]
- 🟡 拓展层：[学习目标 + 活动 + 挑战]
```

### 4. 在线教学教案

```
为在线教学设计教案。

主题：[TOPIC]
平台：[PLATFORM]（如 Zoom/腾讯会议/钉钉）
学生人数：[STUDENT_COUNT]
时长：[DURATION] 分钟

在线教学特别考虑：
1. 注意力管理（每 8-10 分钟切换活动）
2. 互动工具使用（投票/白板/聊天/分组讨论）
3. 技术故障预案
4. 屏幕疲劳缓解策略
5. 在线课堂管理（签到/提问/参与度追踪）

输出完整教案 + 技术准备清单。
```

## 评分标准 / Rubrics

### 5. 通用评分标准生成

```
为以下作业/考试创建详细的评分标准。

作业/考试名称：[ASSESSMENT_NAME]
学科：[SUBJECT]
总分：[TOTAL_SCORE]
考查目标：[LEARNING_OBJECTIVES]

评分标准格式（分析型 Rubric）：
| 评分维度 | 权重 | 优秀(A) | 良好(B) | 合格(C) | 不合格(D) |
|----------|------|---------|---------|---------|-----------|
| [维度1] | XX% | [标准] | [标准] | [标准] | [标准] |
| [维度2] | XX% | [标准] | [标准] | [标准] | [标准] |
| ... | ... | ... | ... | ... | ... |

要求：
- 每个维度的标准具体可衡量
- 总分合理分配
- 包含扣分项说明
- 包含加分项（如有）
```

### 6. 项目/作品评分标准

```
为以下项目/作品创建评分标准。

项目类型：[PROJECT_TYPE]（如编程项目/写作/PPT/实验报告）
学科：[SUBJECT]
评分等级：[GRADE_LEVEL]（如 A/B/C/D 或百分制）

评分维度建议：
- 内容质量（40%）
- 创意和原创性（20%）
- 技术执行（20%）
- 呈现和表达（10%）
- 合作贡献（10%，如是小组项目）

每个维度每个等级的具体描述 + 示例。
```

### 7. 口头报告评分标准

```
为课堂口头报告/演讲创建评分标准。

报告主题：[TOPIC]
时长要求：[DURATION] 分钟
评分维度：

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| 内容准确性 | 30% | 信息准确、深度适当、有论据支撑 |
| 逻辑结构 | 20% | 结构清晰、过渡自然、有条理 |
| 表达能力 | 20% | 语速适中、声音清晰、眼神交流 |
| 视觉辅助 | 15% | PPT/白板使用得当、图文清晰 |
| 时间控制 | 10% | 在规定时间内完成 |
| 回答问题 | 5% | 能回答同学和老师的提问 |

每项细分到 A/B/C/D 等级。
```

## 学生反馈 / Student Feedback

### 8. 作业评语生成

```
为以下学生作业生成个性化评语。

学生姓名：[STUDENT_NAME]
作业内容摘要：[ASSIGNMENT_SUMMARY]
得分：[SCORE]/[TOTAL]
作业类型：[ASSIGNMENT_TYPE]

评语要求：
- 2-3 个具体优点（用实例说明）
- 1-2 个改进建议（具体且可操作）
- 语气：鼓励性、建设性、个性化
- 避免空泛的表扬（如"做得好"）
- 提出一个引导思考的问题
- 总长度 100-150 字

提供 2 个版本：
1. 详细版（适合书面反馈）
2. 简短版（适合口头反馈）
```

### 9. 学期评语

```
为学生撰写学期末综合评语。

学生信息：
- 姓名：[NAME]
- 学科：[SUBJECT]
- 成绩趋势：[GRADE_TREND]（如"期中 75 → 期末 88"）
- 课堂表现：[CLASS_PERFORMANCE]
- 作业完成情况：[HOMEWORK_COMPLETION]
- 特别表现：[SPECIAL_ACHIEVEMENTS]
- 需改进方面：[AREAS_FOR_IMPROVEMENT]

评语要求：
- 150-200 字
- 先肯定优点和进步
- 具体指出成长和变化
- 建设性地提出改进方向
- 表达对下学期的期望
- 语气温暖且专业
- 避免模板化语言
```

```
[CLASS_DATA]

错误类型分析：
| 错误类型 | 频率 | 涉及知识点 | 根因分析 | 教学建议 |

生成反馈：

```

```
   - 拓展阅读
```

## 💡 使用技巧 / Tips

1. **告知学生背景**：年龄段、学习水平、班级规模会显著影响教学设计
2. **明确教学目标**：用布鲁姆分类法描述目标（记忆→理解→应用→分析→评价→创造）
3. **提供课程标准**：如果需要对齐课标，提供课标编号和要求
4. **指定教学法**：如有偏好的教学法（PBL/合作学习/翻转课堂），提前说明
5. **迭代优化**：先生成框架，再逐节深化

## ⚠️ 常见错误 / Common Mistakes

- ❌ 教案只设计"教"不设计"学"（要关注学生活动）
- ❌ 评估标准不透明（学生不知道怎么拿高分）
- ❌ 反馈过于笼统（"做得好"不如"第3段的论据很有力"）
- ❌ 忽略差异化（一个班的学生水平不可能完全一致）
- ❌ 课堂活动没有明确的学习目标（为活动而活动）
