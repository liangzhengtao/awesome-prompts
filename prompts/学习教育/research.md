## 文献综述 / Literature Review

### 1. 文献检索策略

```
为以下研究主题设计系统的文献检索策略。

研究主题：[TOPIC]
研究问题：[RESEARCH_QUESTION]
学科领域：[FIELD]

请提供：
1. 关键词列表（英文+中文）
   - 核心关键词
   - 同义词/近义词
   - 上下位概念词
2. 检索式构建（布尔逻辑）
   - 数据库 1（如 Web of Science）：[检索式]
   - 数据库 2（如 PubMed）：[检索式]
   - 数据库 3（如 CNKI）：[检索式]
3. 筛选标准
   - 时间范围
   - 文献类型
   - 语言
   - 期刊范围
4. 预估文献量和管理建议
```

### 2. 文献综述框架

```
为以下研究主题撰写文献综述框架。

研究主题：[TOPIC]
研究问题：[RESEARCH_QUESTION]
已有文献：[EXISTING_LITERATURE_SUMMARY]

综述框架：
1. 引言（研究背景和综述目的）
2. 主题一：[子主题1]
   - 主要发现
   - 研究方法总结
   - 存在的争议
3. 主题二：[子主题2]
4. 主题三：[子主题3]
5. 研究空白（Gap）分析
   - 现有研究的不足
   - 尚未解决的问题
6. 未来研究方向
7. 总结

要求：
- 每个主题引用 [NUMBER] 篇以上文献
- 使用批判性视角而非简单罗列
- 标注各研究之间的关系（支持/矛盾/补充）
```

### 3. 文献精读分析

```
对以下学术论文进行精读分析。

论文信息：
- 标题：[TITLE]
- 作者：[AUTHORS]
- 期刊：[JOURNAL]
- 年份：[YEAR]

分析框架：
1. 研究问题是什么？
2. 研究假设是什么？
3. 使用了什么方法？
4. 样本/数据来源是什么？
5. 主要发现是什么？
6. 结论是否得到数据支持？
7. 研究局限性有哪些？
8. 对我的研究有什么启示？
9. 可以引用的关键数据/结论
10. 论文评分（1-10）和评价
```

### 4. 研究前沿追踪

```
追踪以下领域的研究前沿和热点。

研究领域：[FIELD]
时间范围：近 [YEARS] 年
关注维度：
- 高被引论文
- 突发主题（Burst Detection）
- 新兴方法论
- 争议性话题

请输出：
1. 近年 Top 10 高影响力论文
2. 5 个研究热点主题
3. 3 个新兴研究方向
4. 方法论趋势
5. 主要学术会议和期刊动态
6. 对未来研究的预判
```

## 假设生成 / Hypothesis Generation

### 5. 研究假设生成

```
基于以下研究背景生成可检验的研究假设。

研究领域：[FIELD]
研究问题：[RESEARCH_QUESTION]
已有发现：[EXISTING_FINDINGS]
理论基础：[THEORETICAL_FRAMEWORK]

请生成：
1. 主假设（1-2 个）
   - H1: [自变量] 与 [因变量] 呈 [正/负] 相关
   - H2: [调节变量] 调节了 [自变量] 对 [因变量] 的影响
2. 对应的零假设
3. 每个假设的理论依据
4. 可操作化的变量定义
5. 预期效应方向和强度
6. 假设检验的统计方法建议
```

### 6. 研究问题提炼

```
将以下宽泛的研究兴趣提炼为具体、可研究的问题。

研究兴趣：[BROAD_INTEREST]
学科领域：[FIELD]
研究层次：[LEVEL]（本科/硕士/博士/博后）

请提供：
1. 从宽泛到具体的递进
   - 宽泛话题 → 一般问题 → 研究问题 → 具体假设
2. 3-5 个备选研究问题
3. 每个问题的评估
   - 原创性（1-10）
   - 可行性（1-10）
   - 重要性（1-10）
   - 数据可获取性（1-10）
4. 推荐的最佳研究问题
5. 研究问题的理论和实践意义
```

### 7. 变量关系分析

```
分析以下研究变量之间的关系。

自变量：[INDEPENDENT_VARS]
因变量：[DEPENDENT_VARS]
控制变量：[CONTROL_VARS]
理论框架：[THEORY]

请分析：
1. 变量关系图（文字描述路径模型）
2. 直接效应假设
3. 间接效应（中介效应）假设
4. 调节效应假设
5. 可能的混淆变量
6. 操作化定义（每个变量如何测量）
7. 推荐的分析方法
```

## 研究设计 / Methodology Design

### 8. 研究方案设计

```
为以下研究问题设计完整的研究方案。

研究问题：[RESEARCH_QUESTION]
学科：[FIELD]
资源约束：[CONSTRAINTS]（时间/预算/人力）

研究方案：
1. 研究设计类型
   - 定量/定性/混合
   - 实验/调查/案例研究/纵向/横截面
2. 样本设计
   - 总体定义
   - 抽样方法
   - 样本量计算和依据
3. 数据收集
   - 工具（问卷/访谈/实验/二手数据）
   - 量表选择和来源
   - 数据收集流程
4. 变量操作化
   - 自变量：定义 + 测量方式
   - 因变量：定义 + 测量方式
   - 控制变量：选择理由
5. 数据分析计划
   - 描述性统计
   - 推断统计
   - 分析软件
6. 伦理考量
7. 时间线
8. 预期局限性
```

### 9. 问卷设计

```
为以下研究设计调查问卷。

研究主题：[TOPIC]
研究假设：[HYPOTHESES]
目标人群：[TARGET_POPULATION]
预计问卷长度：[LENGTH]（5/10/15/20 分钟）

问卷结构：
1. 封面页（知情同意 + 说明）
2. 筛选问题（确保受访者符合要求）
3. 核心变量测量
   - [变量1]：[量表来源]，[题目数] 题
   - [变量2]：[量表来源]，[题目数] 题
4. 人口统计学变量
5. 结束语

每道题目格式：
- 题号
- 题目文字
- 测量方式（李克特5点/7点/是-否/开放题）
- 对应变量

注意：正向题和反向题交替设置。
```

### 10. 访谈提纲设计

```
为以下研究设计半结构化访谈提纲。

研究主题：[TOPIC]
研究问题：[RESEARCH_QUESTION]
受访者特征：[INTERVIEWEE_PROFILE]
预计时长：[DURATION] 分钟

访谈提纲：
1. 开场（建立关系，2 分钟）
   - 自我介绍
   - 研究说明
   - 录音许可
2. 暖场问题（3 分钟）
   - 简单的背景问题
3. 核心问题（[根据时长分配]）
   - 主题 1：[问题1-3]
   - 主题 2：[问题4-6]
   - 主题 3：[问题7-9]
4. 追问提示（Probes）
   - "能具体说说吗？"
   - "能举个例子吗？"
   - "当时是什么感受？"
5. 收尾问题（3 分钟）
   - "还有什么想补充的吗？"
6. 感谢和后续

每个问题标注类型（开放/半开放/投射）和探究目的。
```

## 数据分析 / Data Analysis

### 11. 统计方法选择

```
帮助选择合适的统计分析方法。

研究设计：[RESEARCH_DESIGN]
自变量：[IV_TYPE]（类型 + 水平数）
因变量：[DV_TYPE]（连续/分类/计数）
样本量：[SAMPLE_SIZE]
数据分布：[DISTRIBUTION]（正态/非正态/未知）
研究目的：[PURPOSE]（比较/关联/预测/分类）

请提供：
1. 推荐的统计方法
2. 方法选择理由
3. 前提假设和检验方法
4. 实施步骤（用 [SOFTWARE] 如 SPSS/R/Python）
5. 结果解读指南
6. 效应量报告方式
7. 替代方法（如果前提不满足）
```

### 12. 数据分析报告

```
基于以下数据和分析结果撰写数据分析报告。

研究问题：[RESEARCH_QUESTION]
数据描述：[DATA_DESCRIPTION]
分析方法：[METHOD]
分析结果：[RESULTS]

报告结构：
1. 数据概览
   - 样本描述性统计
   - 数据清洗说明
2. 描述性分析
   - 关键变量的分布
   - 变量间的初步关系
3. 推断性分析
   - 假设检验结果
   - 效应量和置信区间
4. 结果解读
   - 统计显著性 vs 实际意义
   - 与已有研究的比较
5. 结论和讨论
   - 对研究问题的回答
   - 局限性
   - 未来方向

使用 APA 格式报告统计结果。
```

## 论文写作 / Academic Writing

### 15. 论文结构生成

```
为以下研究生成论文结构大纲。

研究主题：[TOPIC]
研究类型：[TYPE]（实证/综述/理论/案例）
目标期刊/学位：[TARGET]
学科：[FIELD]

论文结构：
1. 标题（3 个备选）
2. 摘要（250 字结构：背景-方法-结果-结论）
3. 引言（漏斗结构：宽→窄→研究问题）
4. 文献综述
5. 方法
6. 结果

8. 结论
9. 参考文献格式

- 预计字数
- 核心内容要点
```


### 17. 审稿意见回复

```
帮助回复以下审稿意见。

论文标题：[PAPER_TITLE]
审稿意见：
[REVIEWER_COMMENTS]

回复策略：
1. 感谢审稿人（不要防御）
2. 逐条回复，使用以下结构：
   **审稿人意见：** [原文引用]
   **回复：** [感谢 + 具体修改说明 + 修改位置]
```

## 💡 使用技巧 / Tips

1. **明确学科规范**：不同学科的研究方法和论文格式差异很大
2. **提供已有文献**：告诉 AI 你已经读了什么，避免重复
3. **指定统计软件**：说清楚用 SPSS/R/Python/Stata，代码示例更实用
4. **说明研究阶段**：开题/数据收集/分析/写作各阶段需要的帮助不同
5. **要求 APA/其他格式**：期刊投稿有格式要求，提前说明

## ⚠️ 常见错误 / Common Mistakes

- ❌ 让 AI 生成虚假的文献引用（一定要自己核实）
- ❌ 不检查统计方法的适用前提
- ❌ 文献综述变成文献罗列（要有批判性分析）
- ❌ 研究问题太宽泛（要具体到可检验）
- ❌ 忽略研究伦理审查（尤其是涉及人类受试者的研究）

### 核心 Prompt 示例

**文献检索策略：**
为以下研究主题设计系统的文献检索策略。研究主题：[TOPIC]，研究问题：[RESEARCH_QUESTION]，学科领域：[FIELD]。请提供：关键词列表（英文+中文，含核心关键词、同义词/近义词、上下位概念词）、检索式构建（布尔逻辑，适配 Web of Science/PubMed/CNKI 等数据库）、筛选标准（时间范围、文献类型、语言、期刊范围）、预估文献量和管理建议。

**研究假设生成：**
基于以下研究背景生成可检验的研究假设。研究领域：[FIELD]，研究问题：[RESEARCH_QUESTION]，已有发现：[EXISTING_FINDINGS]，理论基础：[THEORETICAL_FRAMEWORK]。请生成主假设（含自变量、因变量、关系方向）、对应的零假设、理论依据、可操作化的变量定义、预期效应方向和强度、假设检验的统计方法建议。

**研究方案设计：**
为以下研究问题设计完整的研究方案。研究问题：[RESEARCH_QUESTION]，学科：[FIELD]，资源约束：[CONSTRAINTS]。方案包括：研究设计类型（定量/定性/混合）、样本设计（总体定义、抽样方法、样本量计算）、数据收集（工具、量表选择、流程）、变量操作化、数据分析计划、伦理考量、时间线和预期局限性。

**审稿意见回复：**
帮助回复以下审稿意见。论文标题：[PAPER_TITLE]，审稿意见：[REVIEWER_COMMENTS]。回复策略：感谢审稿人，逐条回复（审稿人意见原文引用 + 回复 + 修改内容），对不同意的意见礼貌解释理由并提供证据，给出回复信的整体结构和语气建议。
