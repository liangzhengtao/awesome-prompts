## Twitter/X

### 1. 推文撰写

```
为以下内容撰写一条高互动率的推文。

主题：[TOPIC]
目标受众：[AUDIENCE]
语气：[TONE]（如专业/幽默/激励/教育）
推文类型：[TYPE]（如观点/教程/提问/新闻）

要求：
- 不超过 280 字符
- 第一句话要抓眼球（用数据/反直觉/提问）
- 包含 2-3 个相关话题标签
- 如果适用，加入 emoji 但不过度
- 包含 CTA（如"转发给需要的人"、"你怎么看？"）

请给出 3 个变体供选择。
```

### 2. Twitter Thread 生成

```
将以下主题展开为一个 Twitter Thread（推文串）。

主题：[TOPIC]
核心观点：[KEY_POINTS]
目标：[GOAL]（如教育/分享经验/引发讨论）

Thread 结构：
1/ 🧵 开篇推文（钩子，让人想读下去）
2-8/ 主体推文（每条一个要点，含例子或数据）
9/ 总结推文（回顾关键点）
10/ CTA（关注/转发/评论引导）

每条推文要求：
- 280 字符以内
- 自成一条有价值的推文
- 使用 emoji 增强可读性
- 必要时使用编号
```

### 3. 热点借势推文

```
将以下热点事件与 [BRAND/TOPIC] 关联，撰写借势推文。

热点事件：[TRENDING_TOPIC]
品牌/个人：[BRAND]
关联角度：[ANGLE]

要求：
- 不超过 280 字符
- 自然关联，不牵强
- 避免敏感/争议话题
- 包含热点标签
- 给出 5 个不同角度的变体
```

### 4. 互动型推文

```
设计一条旨在引发高互动的推文。

话题：[TOPIC]
互动形式：[FORMAT]（如投票/提问/填空/选择/挑战）
目标受众：[AUDIENCE]

要求：
- 推文本身就有价值（不是单纯的"你们觉得呢"）
- 降低参与门槛（容易回复）
- 包含争议性或有趣的观点
- 提供 3 个不同互动形式的变体
```

## LinkedIn

### 5. LinkedIn 专业帖子

```
撰写一篇 LinkedIn 专业帖子。

主题：[TOPIC]
行业：[INDUSTRY]
目标：[GOAL]（如个人品牌/行业洞察/经验分享）
帖子类型：[TYPE]（如经验分享/行业观点/职业建议）

LinkedIn 帖子最佳实践：
- 第一行是"钩子"（LinkedIn 折叠，只显示前两行）
- 使用短段落和换行（增加可读性）
- 讲故事而非说教
- 结尾提出问题引发评论
- 长度 1300-1500 字符为佳
- 避免外部链接（LinkedIn 会降低权重）
- 使用行业专业术语建立权威

请提供 2 个变体。
```

### 6. LinkedIn 转型/里程碑帖子

```
撰写一篇庆祝职业里程碑的 LinkedIn 帖子。

里程碑：[MILESTONE]（如升职/新工作/项目上线/工作周年）
反思要点：[REFLECTIONS]
感谢对象：[ACKNOWLEDGMENTS]
建议/教训：[LESSONS]

结构：
1. 吸引人的开头（不是"我很高兴宣布..."）
2. 故事/背景
3. 关键教训或收获
4. 感谢特定的人或团队
5. 对读者的鼓励/启发
6. CTA（如"你有过类似经历吗？"）
```

### 7. LinkedIn 行业洞察帖子

```

趋势/洞察：[INSIGHT]

要求：
- 用数据开头吸引注意
- 提供独特视角（不是人云亦云）
- 引用可信来源
- 给出可操作的建议
- 邀请读者分享他们的观点
```

## 💡 使用技巧 / Tips

1. **平台适配**：不同平台有不同的最佳实践，指定平台让 AI 输出更合适的内容
2. **提供参考**：分享你欣赏的账号风格，AI 可以模仿
3. **批量生成**：一次性要求多个变体，从中挑选最佳
4. **指定字数限制**：每个平台有不同的字数限制，提前告知 AI
5. **加入品牌调性**：描述你的品牌个性（如"专业但不无聊"），保持一致性

## ⚠️ 常见错误 / Common Mistakes

- ❌ 一个 Prompt 生成所有平台内容（每个平台应单独优化）
- ❌ 不指定目标受众，内容缺乏针对性
- ❌ 忽略平台算法特性（如 LinkedIn 不喜欢外部链接）
- ❌ 不测试不同变体，只用第一个版本
- ❌ 内容过于正式或过于随意（应匹配平台调性）
