## 欢迎序列 / Welcome Series

### 1. 新用户欢迎邮件序列

```
为 [PRODUCT/SERVICE] 设计一封欢迎邮件序列（共 [NUMBER] 封）。

产品/服务：[PRODUCT_DESCRIPTION]
目标用户：[TARGET_USER]
核心价值主张：[VALUE_PROPOSITION]
用户注册来源：[SIGNUP_SOURCE]

每封邮件需要包含：
- 主题行（3 个变体）
- 预览文字
- 邮件正文（HTML 友好）
- CTA 按钮文案
- 发送时间建议（注册后第 X 天）

序列规划：
第 1 封：欢迎 + 设定期望
第 2 封：核心价值介绍
第 3 封：快速上手指南
第 4 封：社交证明/案例
第 5 封：引导付费/下一步
```

### 2. 双重确认（Double Opt-in）邮件

```
撰写一封高效的双重确认邮件。

品牌：[BRAND]
订阅内容：[SUBSCRIPTION_CONTENT]
激励（如有）：[INCENTIVE]（如"确认后获取免费指南"）

邮件要求：
- 主题行简洁明了（含品牌名）
- 正文在 50 字以内
- 大且显眼的确认按钮
- 说明确认的好处
- 说明不确认的后果
- 友好的语气
- 包含备用文本链接
```

## 培育序列 / Nurture Sequences

### 3. 内容培育序列

```
设计一个 [NUMBER] 封邮件的内容培育序列。

行业：[INDUSTRY]
目标受众：[AUDIENCE]
最终目标：[END_GOAL]（如免费试用/预约演示/购买）
内容资源：[CONTENT_ASSETS]（如博客/白皮书/案例/视频）

每封邮件需要：
- 主题行（含变体）
- 核心价值点
- 内容摘要（不是全文，是吸引点击的摘要）
- CTA（逐步加强）
- 发送间隔建议

序列策略：
- 前期：纯价值，不推销
- 中期：价值 + 软性引导
- 后期：明确的行动号召
```

### 4. 产品教育序列

```
为 [PRODUCT] 设计产品教育邮件序列。

产品：[PRODUCT_NAME]
核心功能：[KEY_FEATURES]
用户痛点：[PAIN_POINTS]
用户活跃度问题：[ENGAGEMENT_ISSUE]

序列结构（5-7 封邮件）：
1. 功能亮点概览
2. 功能 A 深度教程
3. 功能 B 深度教程
4. 高级技巧和窍门
5. 用户案例分享
6. 隐藏功能揭秘
7. 进阶功能引导

每封邮件风格：
- 简短易读（200 字以内正文）
- 包含 GIF/截图位置标注
- 单一 CTA
```

### 5. 试用期培育序列

```
为 [PRODUCT] 的 [TRIAL_DAYS] 天免费试用期设计培育序列。

产品：[PRODUCT]
试用天数：[TRIAL_DAYS]
关键激活行为：[KEY_ACTIVATION_EVENTS]
转化目标：[CONVERSION_GOAL]

序列时间线：
- Day 0：欢迎 + 快速开始
- Day 1：第一个"啊哈"时刻引导
- Day 3：核心功能教程
- Day 5：成功案例分享
- Day 7：进度检查 + 高级功能
- Day 10：社交证明 + 常见顾虑
- Day [TRIAL_DAYS-2]：即将到期提醒
- Day [TRIAL_DAYS]：最后机会 + 优惠

每封邮件包含主题行、正文、CTA。
```

## 销售邮件 / Sales Emails

### 6. 产品发布邮件

```
为以下产品/功能发布撰写销售邮件。

产品/功能：[PRODUCT_FEATURE]
目标受众：[AUDIENCE]
核心卖点：[SELLING_POINTS]
定价信息：[PRICING]
限时优惠：[LIMITED_OFFER]（如有）

邮件结构：
1. 引人注目的主题行（3 个变体）
2. 开头钩子（痛点或令人兴奋的消息）
3. 产品介绍（聚焦用户利益而非功能）
4. 3 个核心卖点（每个配一句话说明）
5. 社交证明（用户评价/数据）
6. 价格和优惠
7. 清晰的 CTA
8. P.S.（重申紧迫感或额外优惠）
```

### 7. 季节性促销邮件

```
为 [SEASON/HOLIDAY] 促销活动撰写邮件。

品牌：[BRAND]
促销活动：[PROMOTION]
折扣力度：[DISCOUNT]
活动时间：[DATE_RANGE]
目标产品：[PRODUCTS]

请提供 3 封系列邮件：
1. 预热邮件（活动前 2 天）

3. 最后提醒（活动结束前 24 小时）

- 2 个主题行变体

- CTA 按钮
```

### 8. 追加销售/交叉销售邮件

```
撰写一封追加销售或交叉销售邮件。

当前产品/计划：[CURRENT_PLAN]
推荐升级/产品：[RECOMMENDED_UPGRADE]
升级理由：[UPGRADE_REASON]
优惠信息：[OFFER]

邮件策略：
- 不是硬推，而是展示升级后的价值
- 用"你错过了什么"的角度
- 包含升级用户的故事/数据
- 提供限时优惠降低决策门槛
- 简化升级流程（一键升级链接）
```

### 9. 购物车放弃挽回

```
设计购物车放弃挽回邮件序列（3 封）。

产品类型：[PRODUCT_TYPE]
平均订单价值：[AOV]
挽回优惠权限：[RECOVERY_OFFER]

第 1 封（放弃后 1 小时）：
- 提醒型，不用优惠
- 展示弃购商品
- 简单的"完成购买"CTA

第 2 封（放弃后 24 小时）：
- 展示商品评价/社交证明
- 解答常见疑虑
- 软性 CTA

第 3 尹（放弃后 48 小时）：
- 提供限时优惠
- 创建紧迫感
- 强力 CTA

每封邮件需主题行、正文、CTA。
```

## 邮件优化 / Email Optimization

### 13. 主题行优化

```
为以下邮件生成 [NUMBER] 个高打开率的主题行变体。

邮件目的：[PURPOSE]
核心信息：[CORE_MESSAGE]
目标受众：[AUDIENCE]
发送者：[SENDER_NAME]

主题行类型各 [NUMBER] 个：
- 数字型（如"3 个提升效率的技巧"）
- 好奇型（如"大多数人不知道的秘密"）
- 紧迫型（如"仅剩 [X] 小时"）
- 个性化型（含 [FIRST_NAME] 等变量）
- 问题型（如"你还在为 X 烦恼吗？"）
- 列表型（如"[TOPIC] 完整指南"）

每个附上预估打开率（高/中/低）和推荐理由。
```

### 14. 邮件正文 A/B 测试

```
为以下邮件的正文部分生成 A/B 测试版本。

- 版本 B：修改 [VARIABLE]

```

## 示例输出 / Example Output

**模糊 Prompt** → "帮我写一封营销邮件"

**精确 Prompt** → "为 SaaS 产品写一封面向试用期第 5 天但未完成关键操作的用户的产品教育邮件，语气友好专业，核心是引导他们完成首次数据导入，主题行要制造好奇心"

| 维度 | 模糊 Prompt | 精确 Prompt |
|------|------------|------------|
| 用户阶段 | 不明确 | 试用第 5 天未激活 |
| 目标 | 不明确 | 引导完成数据导入 |
| 语气 | AI 自行决定 | 友好专业 |
| 主题行 | 普通 | 制造好奇心 |
| 可用性 | 需大幅修改 | 接近终稿 |

## 💡 使用技巧 / Tips

1. **明确用户旅程阶段**：不同阶段的邮件策略完全不同
2. **提供用户数据**：如果有用户行为数据，让 AI 帮你做个性化
3. **A/B 测试思维**：每个关键元素都要求多个变体
4. **合规提醒**：告知 AI 目标市场的邮件法规（如 GDPR、CAN-SPAM）
5. **品牌指南**：提供品牌调性指南，保持邮件一致性

## ⚠️ 常见错误 / Common Mistakes

- ❌ 邮件正文过长，失去读者注意力
- ❌ CTA 不明确或太多（每封邮件一个主要 CTA）
- ❌ 忽略移动端显示（超过 50% 的邮件在手机上打开）
- ❌ 不做 A/B 测试，凭感觉优化
- ❌ 忽略退订体验（退订也是品牌触点）
