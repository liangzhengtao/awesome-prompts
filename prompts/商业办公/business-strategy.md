## SWOT 分析 / SWOT Analysis

### 1. 全面 SWOT 分析

```
为以下企业/项目进行全面的 SWOT 分析。

公司/项目名称：[COMPANY_NAME]
行业：[INDUSTRY]
产品/服务：[PRODUCT_DESCRIPTION]
目标市场：[TARGET_MARKET]
当前阶段：[STAGE]（如初创/成长/成熟）
主要营收模式：[REVENUE_MODEL]

请按以下格式输出：

## Strengths（优势）
- 列出 5-8 个内部优势
- 每个优势配一句话说明和支撑证据

## Weaknesses（劣势）
- 列出 5-8 个内部劣势
- 每个劣势配一句话说明和影响分析

## Opportunities（机会）
- 列出 5-8 个外部机会
- 每个机会配一句话说明和把握难度

## Threats（威胁）
- 列出 5-8 个外部威胁
- 每个威胁配一句话说明和应对建议

最后输出：
- SO 策略（利用优势把握机会）
- WO 策略（克服劣势把握机会）
- ST 策略（利用优势应对威胁）
- WT 策略（克服劣势规避威胁）
```

### 2. 快速 SWOT（产品级别）

```
对以下产品做快速 SWOT 分析，聚焦战略决策。

产品名称：[PRODUCT_NAME]
直接竞品：[COMPETITORS]
产品独特卖点：[USP]

输出要求：
- 每象限 3-5 个要点
- 每个要点用一句话
- 最后给出 3 个最高优先级的战略行动
```

### 3. SWOT + 评分矩阵

```
为以下业务做 SWOT 分析并量化评估。

业务描述：[BUSINESS_DESCRIPTION]
评估维度：

优势和劣势评估（1-10 分）：
| 因素 | 得分 | 说明 |
|------|------|------|
| 品牌影响力 | ? | ... |
| 技术能力 | ? | ... |
| 团队实力 | ? | ... |
| 财务状况 | ? | ... |
| 产品成熟度 | ? | ... |

机会和威胁评估（影响力 1-10 × 概率 1-10）：
| 因素 | 影响力 | 概率 | 综合得分 | 说明 |
|------|--------|------|----------|------|
| ... | ... | ... | ... | ... |

输出综合评估报告和战略建议。
```

## 竞争分析 / Competitive Analysis

### 4. 竞品深度分析

```
对以下产品进行深度竞品分析。

我们的产品：[OUR_PRODUCT]
竞品列表：[COMPETITOR_LIST]
分析维度：
- 功能对比
- 定价策略
- 目标用户
- 市场份额
- 优劣势

输出格式：
1. 竞品概况表（每个竞品一段话介绍）
2. 功能对比矩阵（表格形式）
3. 定价对比
4. 竞争定位图（文字描述，2x2 矩阵）
5. 差异化机会
6. 战略建议
```

### 5. 竞品营销策略分析

```
分析以下竞品的营销策略。

竞品名称：[COMPETITOR_NAME]
竞品网站：[COMPETITOR_WEBSITE]
分析重点：
- 内容营销策略
- 社交媒体策略
- SEO 策略
- 付费广告策略
- 邮件营销策略

请输出：
1. 各渠道策略概要
2. 优势和可借鉴之处
3. 弱点和我们可以切入的机会
4. 具体可执行的策略建议
```

### 6. 护城河分析

```
分析以下企业的竞争护城河（Moat）。

企业名称：[COMPANY_NAME]
行业：[INDUSTRY]
业务描述：[BUSINESS]

请评估以下护城河维度（1-10 分）：
1. 品牌效应 - 用户选择是否基于品牌
2. 网络效应 - 用户增长是否增加产品价值
3. 转换成本 - 用户切换竞品的成本
4. 成本优势 - 是否有结构性成本优势
5. 规模经济 - 规模是否带来效率优势
6. 知识产权 - 专利/技术壁垒
7. 监管壁垒 - 是否有准入牌照等

输出：
- 各维度评分和分析
- 综合护城河强度评估
- 加固护城河的建议
```

## 市场调研 / Market Research

### 7. 目标市场分析

```
为以下产品/服务分析目标市场。

产品/服务：[PRODUCT]
行业：[INDUSTRY]

请分析：
1. TAM（总可寻址市场）- 估算规模
2. SAM（可服务市场）- 实际可以服务的部分
3. SOM（可获取市场）- 短期内可以获取的部分
4. 市场增长趋势（过去 3 年 + 未来 3 年预测）
5. 市场驱动因素
6. 市场阻碍因素
7. 关键成功因素

输出格式：数据 + 分析 + 图表建议位置
```

产品描述：[PRODUCT_DESCRIPTION]

请创建 3-4 个典型用户画像，每个包含：

- 消费者行为变化

公司名称：[COMPANY]

上年业绩：[LAST_YEAR_PERFORMANCE]

### 15. 增长策略

```
为以下业务制定增长策略。

业务名称：[BUSINESS]

增长目标：[GROWTH_TARGET]（如"年营收增长 50%"）

```

### 16. 危机应对策略

```
为以下商业危机制定应对策略。

危机类型：[CRISIS_TYPE]（如经济下行/供应链中断/公关危机/技术变革）

公司信息：[COMPANY_INFO]

1. 即时应对（0-30 天）
   - 现金流保护

2. 短期调整（1-6 个月）

   - 成本优化

3. 中长期恢复（6-18 个月）
   - 业务模式调整
   - 新机会识别
   - 韧性建设
```

## 💡 使用技巧 / Tips

1. **提供财务数据**：有数据支持的分析远比空谈有价值
2. **明确时间框架**：战略规划必须有明确的时间范围
3. **指定决策类型**：告诉 AI 你在做什么决策（进入新市场/定价/投资），输出会更聚焦
4. **要求可执行性**：要求 AI 输出具体行动步骤，而不仅仅是分析
5. **结合行业知识**：提供行业背景信息，让分析更准确

## ⚠️ 常见错误 / Common Mistakes

- ❌ 不提供足够的业务上下文，导致分析过于泛化
- ❌ 只看分析不看行动，战略分析的价值在于指导行动
- ❌ 忽略竞争环境，孤立地分析自己的业务
- ❌ 过度依赖 AI 的市场数据估算（可能不准确）
- ❌ 不做假设标注，分不清事实和推测
