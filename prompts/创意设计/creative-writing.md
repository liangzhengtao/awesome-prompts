## 故事开头 / Story Starters

### 1. 悬念式开头

```
用以下要素创作一个悬念式短篇故事开头（300-500 字）。

类型：[GENRE]（如悬疑/科幻/奇幻/文学/惊悚）
时间设定：[TIME_SETTING]（如现代/维多利亚时代/未来 2200 年）
地点设定：[LOCATION]（如伦敦老城区/太空站/虚构小镇）
核心悬念：[MYSTERY]（如"一具不可能存在的尸体"、"一封来自未来的信"）
主人公：[PROTAGONIST]（简要描述）

要求：
- 第一句话就制造悬念
- 不直接揭示发生了什么，而是通过细节暗示
- 引入一个有吸引力的主人公
- 读完开头让人想知道接下来发生了什么
- 展示而非叙述（Show, don't tell）
```

### 2. 对话式开头

```
用一段引人入胜的对话开始一个故事。

类型：[GENRE]
对话场景：[SCENE]（如审讯室/咖啡馆/战场/婚礼）
两个人物：[CHARACTER_A] 和 [CHARACTER_B]
隐藏的秘密：[SECRET]（对话表面之下正在发生什么）

要求：
- 对话要有潜台词（表面说的和真正意思不同）
- 通过对话自然地展现人物性格
- 不用过多对话标签（"他说"/"她道"）
- 让读者通过对话猜测两人的关系和处境
- 对话中包含一个转折或意外
```

### 3. 环境描写式开头

```
用一段沉浸式的环境描写开始一个故事。

场景：[SCENE_DESCRIPTION]
天气/时间：[WEATHER_TIME]
氛围：[MOOD]（如压抑/温馨/诡异/壮丽）
隐藏的线索：[HIDDEN_CLUE]（环境中的某个细节将在后文变得重要）

要求：
- 使用五感描写（视觉/听觉/嗅觉/触觉/味觉）
- 环境暗示即将发生的事情
- 至少一个不寻常的细节（制造不安感或好奇心）
- 300-500 字
- 结尾自然过渡到人物出场
```

### 4. "如果"式故事种子

```
基于以下"如果"前提，创作一个故事大纲和开头。

核心前提：如果 [PREMISE] 会怎样？

示例前提：
- 如果人类可以记住未来而非过去会怎样？
- 如果你的影子是一个独立的生命体会怎样？
- 如果死亡是一种可治愈的疾病会怎样？

请输出：
1. 故事大纲（500 字以内）
2. 世界观设定
3. 主要冲突
4. 主人公简介
5. 故事开头（500 字）
6. 结局方向（2-3 个可能的结局）
```

### 5. 多线叙事开头

```
创作一个多线叙事的故事开头，同时开启 2-3 条故事线。

线 1：[CHARACTER_A] 在 [SETTING_A] 遇到 [SITUATION_A]
线 2：[CHARACTER_B] 在 [SETTING_B] 遇到 [SITUATION_B]
线 3：[CHARACTER_C] 在 [SETTING_C] 遇到 [SITUATION_C]
交汇点：[CONNECTION]（三条线最终如何交汇）

每条线 150-200 字，要求：
- 每条线都能独立吸引读者
- 风格和节奏因线而异
- 暗示三条线之间的联系
- 交替切换制造悬念
```

## 角色创建 / Character Creation

### 6. 主角塑造

```
为以下故事创建一个立体的主角。

故事类型：[GENRE]
故事主题：[THEME]
时代背景：[SETTING]

请创建：
1. 基本信息（姓名/年龄/外貌/职业）
2. 性格特征（3 个优点 + 3 个缺点）
3. 内心矛盾（渴望什么 vs 恐惧什么）
4. 核心伤口（Core Wound - 过去经历塑造了现在的他/她）
5. 角色弧线（故事开始→中间→结束时的变化）
6. 说话方式和口头禅
7. 独特习惯或癖好
8. 最大秘密
9. 关系网（与 3-5 个配角的关系）
10. 角色独白（用第一人称写 200 字内心独白）
```

### 7. 反派塑造

```
创建一个有深度的反派角色。

故事类型：[GENRE]
与主角的关系：[RELATIONSHIP]

要求——好的反派应该是：
1. 有自己的逻辑（从他/她自己的视角看是"对的"）
2. 有令人同情的过去
3. 有明确的目标和动机
4. 是主角的镜像（某种意义上是主角的另一种可能）
5. 有自己的道德底线

请提供：
- 基本信息和外貌
- 动机和目标
- "堕落"的起源故事
- 与主角的对立关系说明
- 反派自认为是英雄的理由
- 关键场景：展示反派有人性的一面
```

### 8. 群像角色设计

```
为以下故事设计一组配角，组成有化学反应的角色群像。

故事类型：[GENRE]
团队/群体背景：[GROUP_CONTEXT]（如冒险队/办公室/家族/学校班级）
人数：[NUMBER] 人

每个角色需要：
- 姓名和一句话标签（如"话最少但关键时刻最可靠的人"）
- 核心性格（用 MBTI 或原型描述）
- 在团队中的功能角色
- 与其他成员的关系
- 独特的说话方式
- 角色的隐藏面

群像设计原则：
- 性格互补，避免雷同
- 至少一对有趣的对立关系
- 至少一对意外的同盟关系
- 每个角色都有离开故事的理由（但留下来的理由更强）
```

### 9. 角色对话测试

```
通过以下"角色测试"来检验角色的立体度。

角色名：[CHARACTER_NAME]
角色设定：[CHARACTER_SETTING]

请回答以下问题（用角色的声音回答，而非第三人称描述）：

1. 用一句话介绍你自己。
2. 你早上醒来想到的第一件事是什么？
3. 你最害怕什么？（不允许说"不知道"或"没什么"）
4. 如果可以改变过去的一件事，你会改变什么？
5. 你在什么情况下会说谎？
6. 你对 [STORY_THEME] 的看法是什么？
7. 你的朋友会用哪三个词形容你？你自己呢？
8. 你人生中最骄傲和最羞耻的时刻分别是什么？
```

## 世界构建 / World Building

### 10. 奇幻世界设定

```
创建一个原创奇幻世界的基础设定。

世界观基调：[TONE]（如黑暗/史诗/轻松/蒸汽朋克）
魔法系统类型：[MAGIC_SYSTEM]（如有代价的/天赋的/物品驱动的/仪式性的）
技术水平：[TECH_LEVEL]（如中世纪/文艺复兴/工业革命/混合）
灵感来源：[INSPIRATION]（如东方神话/北欧/原创/混合）

请构建：
1. 世界名称和概述（一段话）
2. 地理（主要大陆/区域和特征）
3. 魔法系统规则（来源/限制/代价）
4. 主要种族/民族（3-5 个）
5. 政治格局（主要势力和冲突）
6. 历史大事（影响当前世界的关键事件）
7. 宗教/信仰体系
8. 经济体系（货币/贸易/资源）
9. 日常生活概貌（普通人的生活是什么样的）
10. 世界的核心矛盾/张力（驱动故事的底层冲突）
```

### 11. 科幻世界设定

```
创建一个硬科幻/软科幻世界设定。

科幻类型：[TYPE]（硬科幻/软科幻/赛博朋克/太空歌剧/末日/乌托邦）
时间设定：[TIME]（近未来 50 年/中未来 200 年/远未来 1000+ 年）
核心科技设定：[CORE_TECH]（如 AI 觉醒/曲率引擎/基因改造/意识上传）
社会形态：[SOCIETY_TYPE]（如星际联邦/公司国家/AI 管理/后稀缺社会）

请构建：
1. 科技树概述（哪些技术成熟了，哪些没有）
2. 核心科技的原理（简单但自洽）
3. 社会结构和阶层
4. 地球/母星现状
5. 太空殖民/扩展情况
6. 政治和治理体系
7. 人类增强/改造程度
8. 核心冲突来源
9. 日常科技（普通人的日常使用什么科技）
10. 世界观的哲学主题（这个设定在探讨什么问题）
```

### 12. 场景详细描写

```
为以下场景写一段沉浸式的环境描写。

场景：[SCENE]
世界背景：[WORLD_CONTEXT]
时间：[TIME]
天气：[WEATHER]
正在发生的事：[EVENT]

描写要求（五感描写）：
👁️ 视觉：颜色、光线、形状、运动
👂 听觉：环境声音、背景音乐、寂静
👃 嗅觉：空气中的气味、食物、自然
✋ 触觉：温度、风、质地、湿度
👅 味觉：如果场景中有的话

额外：
- 至少一个不寻常的细节
- 通过环境暗示社会/文化信息
- 控制在 300-500 字
- 用第三人称限知视角
```

## 对话生成 / Dialogue Generation

### 13. 冲突对话

```
写一段两个角色之间的冲突对话。

角色 A：[CHARACTER_A_NAME] - [性格]，[立场]
角色 B：[CHARACTER_B_NAME] - [性格]，[立场]
冲突主题：[CONFLICT]
场景：[SCENE]

要求：
- 对话有潜台词（不是直接说出想法）
- 通过对话展示性格差异
- 情绪递进（从平静→激动→爆发/和解）
- 包含非语言动作描写（表情/手势/停顿）
- 不要所有句子都用"他/她说"
- 300-500 字
```

### 14. 日常对话

```
写一段自然、真实的日常对话。

角色：[NUMBER] 人
关系：[RELATIONSHIP]（如老友/情侣/父子/同事）
场景：[SCENE]
表面主题：[TOPIC]（他们在聊什么）
隐藏主题：[SUBTEXT]（真正想表达但没说出来的）

要求：
- 像真人说话（有打断、跑题、省略、语气词）
- 通过日常对话展示关系动态
- 潜台词比台词更有趣
- 用动作和环境穿插打断对话节奏
- 300-500 字
```

### 15. 独白/内心戏

```
写一段角色的内心独白。

角色：[CHARACTER]
情境：[SITUATION]
内心矛盾：[INNER_CONFLICT]
情绪起点：[STARTING_EMOTION]
情绪终点：[ENDING_EMOTION]

要求：
- 用第一人称
- 体现角色独特的思维方式
- 思维跳跃（像真正的内心活动）
- 自我欺骗和自我察觉交替
- 通过内心活动展示性格
- 200-400 字
```

### 16. 信息传递对话

```
写一段在对话中自然地传递关键信息的场景。

需要传递的信息：[KEY_INFORMATION]
对话场景：[SCENE]
对话者关系：[RELATIONSHIP]
信息对剧情的影响：[IMPACT]

要求：
- 信息不是直接说出来的（通过暗示/故事/争论传递）
- 读者能自然地获取信息
- 信息的传递方式符合角色性格
- 同时推进角色关系发展
- 300-500 字
```

## 诗歌与散文 / Poetry & Prose

### 17. 主题诗歌

```
用以下主题创作一首诗歌。

主题：[THEME]
情感基调：[EMOTION]
诗歌形式：[FORM]（如自由诗/十四行诗/俳句/古体诗/现代诗）
语言：[LANGUAGE]
灵感意象：[IMAGERY]（如海/月亮/城市/季节）

要求：
- 意象具体，避免空泛的抒情
- 有节奏感（注意音韵和停顿）
- 最后一句有余韵（让人回味）
- 用新视角看旧主题
```

### 18. 散文片段

```
写一篇关于 [TOPIC] 的散文片段。

主题：[TOPIC]
风格：[STYLE]（如抒情/叙事/议论/意识流）
长度：[LENGTH] 字
情感：[EMOTION]

要求：
- 语言有质感（注意用词的音韵和意象）
- 结构自由但有内在逻辑
- 有个人独特的视角
- 细节具体而非笼统
- 结尾回扣开头，形成闭环
```

### 19. 闪小说

```
创作一篇闪小说（Flash Fiction）。

主题/前提：[PREMISE]
字数限制：[WORD_COUNT] 字以内（通常 100-1000 字）
类型：[GENRE]

要求：
- 有一个完整的叙事弧（开头-发展-转折-结尾）
- 最后一句制造反转或震撼
- 每个字都有存在的理由
- 留白比叙述更多（读者需要自己填补）
- 读完让人久久不能释怀
```

### 20. 歌词创作

```
为以下主题创作一首歌词。

主题：[THEME]
音乐风格：[STYLE]（如流行/摇滚/民谣/说唱/R&B）
情感：[EMOTION]
参考曲目：[REFERENCE_SONGS]（可选）

歌词结构：
- Verse 1（第一段）：设定场景/故事
- Pre-Chorus（预副歌）：情绪升级
- Chorus（副歌）：核心主题，最抓耳的旋律对应
- Verse 2（第二段）：深化/发展
- Chorus（副歌）：重复
- Bridge（桥段）：转折/高潮
- Final Chorus（最后副歌）：变化或加强

要求：
- 副歌旋律感强（读起来就有节奏）
- 押韵自然不刻意
- 有画面感的歌词比抽象的情感表达更有力
- 歌词要能唱出来（朗读测试）
```

## 💡 使用技巧 / Tips

1. **提供约束**：字数限制、风格限制、角色限制——限制反而激发创意
2. **给参考**：如果有喜欢的作家/作品风格，告诉 AI
3. **迭代创作**：先生成框架，再逐段深化，质量远高于一次性生成
4. **角色声音**：要求 AI "用角色的声音"写对话，而非旁白描述
5. **情感弧线**：无论故事还是诗歌，都应有情感的起伏变化
6. **Show don't tell**：始终要求 AI 展示而非叙述（用行动和细节，而非形容词）

## ⚠️ 常见错误 / Common Mistakes

- ❌ 太笼统（"写个故事"不如"写一个关于失忆侦探的悬疑故事开头"）
- ❌ 一次性生成整篇长文（分段生成质量更高）
- ❌ 不指定风格/基调（AI 可能生成与你期望完全不同的东西）
- ❌ 不做修改直接使用（AI 的创作是起点，不是终点）
- ❌ 忽视角色一致性（多轮对话中角色可能"漂移"，需要提醒）
