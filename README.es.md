## 🤔 ¿Por qué Awesome Prompts?

### Antes (Prompt vago) ❌

```
帮我写个代码审查
```

### Después (Prompt preciso) ✅

```
Eres un ingeniero de seguridad senior. Realiza una auditoría de seguridad OWASP Top 10 del siguiente código.

Lenguaje: Python
Framework: Django
Código:
[paste your code]

Por favor, genera la salida con el siguiente formato:
1. 🔴 Vulnerabilidades críticas (Critical)
2. 🟠 Vulnerabilidades altas (High)
3. 🟡 Vulnerabilidades medias (Medium)
4. 🔵 Vulnerabilidades bajas (Low)

Cada problema debe incluir: descripción, nivel de riesgo, escenario de ataque, recomendaciones de corrección (con ejemplos de código)
```

**Resultado: una salida 10 veces mejor. Cada vez.**

## 🚀 Inicio rápido

### 1. Explorar

Elige una categoría de arriba y encuentra el prompt que se adapte a tus necesidades.

### 2. Copiar

Copia la plantilla de prompt y reemplaza `[VARIABLES]` con tu información específica.

### 3. Pegar y obtener resultados

Pega en tu herramienta de IA favorita (ChatGPT, Claude, Gemini, etc.) y obtén resultados de alta calidad.

---

## 📖 Guía de uso

### Variables

Todos los prompts usan `[VARIABLES]` que necesitas reemplazar:

```
[TOPIC]       → tu tema específico
[LANGUAGE]    → tu lenguaje de programación
[AUDIENCE]    → tu público objetivo
[CODE]        → tu código real
```

### Consejos

1. **Sé específico**: Cuanto más contexto proporciones, mejor será el resultado.

2. **Itera**: Usa la primera salida como punto de partida y luego refínala.

3. **Combina**: Mezcla prompts de diferentes categorías para tareas complejas.

4. **Personaliza**: Modifica los prompts para adaptarlos a tu flujo de trabajo y estilo.
