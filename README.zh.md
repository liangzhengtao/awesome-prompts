## 🤔 为什么选择 Awesome Prompts？

### 使用前（模糊的 Prompt）❌

```
帮我写个代码审查
```

### 使用后（精确的 Prompt）✅

```
你是一位资深安全工程师，请对以下代码进行 OWASP Top 10 安全审查。

语言：Python
框架：Django
代码：
[paste your code]

请按以下格式输出：
1. 🔴 严重漏洞（Critical）
2. 🟠 高危漏洞（High）
3. 🟡 中危漏洞（Medium）
4. 🔵 低危漏洞（Low）

每个问题请包含：问题描述、风险等级、攻击场景、修复建议（含代码示例）
```

**结果：每次都能获得 10 倍更好的输出。**

## 📖 使用指南

### 变量

所有 Prompt 使用 `[VARIABLES]`，你需要替换它们：

```
[TOPIC]       → 你的具体主题
[LANGUAGE]    → 你的编程语言
[AUDIENCE]    → 你的目标受众
[CODE]        → 你的实际代码
```

### 技巧

1. **具体化**：提供的上下文越多，输出越好。
2. **迭代**：将第一次输出作为起点，然后优化。
3. **组合**：组合不同分类的 Prompt 来完成复杂任务。
4. **定制**：修改 Prompt 以适配你的工作流程和风格。
