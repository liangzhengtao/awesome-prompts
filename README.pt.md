## 🤔 Por que Awesome Prompts?

### Antes (Prompt vago) ❌

```
Escreva uma revisão de código para mim
```

### Depois (Prompt preciso) ✅

```
Você é um engenheiro de segurança sênior, realize uma auditoria de segurança OWASP Top 10 no seguinte código.

Linguagem: Python
Framework: Django
Código:
[cole seu código]

Por favor, saia no seguinte formato:
1. 🔴 Vulnerabilidades Críticas
2. 🟠 Vulnerabilidades Altas
3. 🟡 Vulnerabilidades Médias
4. 🔵 Vulnerabilidades Baixas

Cada problema deve incluir: descrição, nível de risco, cenário de ataque, sugestão de correção (com exemplo de código)
```

**Resultado: saída 10x melhor. Toda vez.**

## 🚀 Início Rápido

### 1. Navegue

Escolha uma categoria acima e encontre o prompt que atende às suas necessidades.

### 2. Copie

Copie o template do prompt e substitua `[VARIABLES]` com suas informações específicas.

### 3. Cole & Obtenha Resultados

Cole em sua ferramenta de IA favorita (ChatGPT, Claude, Gemini, etc.) e obtenha resultados de alta qualidade.

---

## 📖 Como Usar

### Variáveis

Todos os prompts usam `[VARIABLES]` que você precisa substituir:

```
[TOPIC]       → seu tópico específico
[LANGUAGE]    → sua linguagem de programação
[AUDIENCE]    → seu público-alvo
[CODE]        → seu código real
```

### Dicas

1. **Seja específico**: Quanto mais contexto você fornecer, melhor a saída.

2. **Itere**: Use a primeira saída como ponto de partida, depois refine.

3. **Combine**: Misture prompts de diferentes categorias para tarefas complexas.

4. **Personalize**: Modifique os prompts para se adequar ao seu fluxo de trabalho e estilo.
