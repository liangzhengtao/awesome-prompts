## 🤔 لماذا نماذج الأوامر الرائعة؟

### قبل (أمر غامض) ❌

```
اكتب لي مراجعة كود
```

### بعد (أمر دقيق) ✅

```
أنت مهندس أمان كبير، يرجى إجراء مراجعة أمان OWASP Top 10 للكود التالي.

اللغة: Python
الإطار: Django
الكود:
[الصق كودك]

يرجى الإخراج بالتنسيق التالي:
1. 🔴 ثغرات حرجة (Critical)
2. 🟠 ثغرات عالية الخطورة (High)
3. 🟡 ثغرات متوسطة الخطورة (Medium)
4. 🔵 ثغرات منخفضة الخطورة (Low)

كل مشكلة يجب أن تتضمن: وصف المشكلة، مستوى الخطورة، سيناريو الهجوم، اقتراحات الإصلاح (مع أمثلة كود)
```

**النتيجة: إخراج أفضل بـ 10 مرات. في كل مرة.**

## 🚀 البدء السريع

### 1. تصفّح

اختر فئة من أعلاه وابحث عن النموذج الذي يناسب احتياجاتك.

### 2. انسخ

انسخ قالب النموذج واستبدل `[VARIABLES]` بمعلوماتك المحددة.

### 3. الصق واحصل على النتائج

الصق في أداة AI المفضلة لديك (ChatGPT، Claude، Gemini، إلخ) واحصل على نتائج عالية الجودة.

---

## 📖 كيفية الاستخدام

### المتغيرات

جميع النماذج تستخدم `[VARIABLES]` التي تحتاج إلى استبدالها:

```
[TOPIC]       → موضوعك المحدد
[LANGUAGE]    → لغة البرمجة الخاصة بك
[AUDIENCE]    → جمهورك المستهدف
[CODE]        → الكود الفعلي الخاص بك
```

### نصائح

1. **كن محددًا**: كلما زودت بمزيد من السياق، كانت النتائج أفضل.

2. **كرّر**: استخدم الإخراج الأول كنقطة انطلاق، ثم قم بالتحسين.

3. **اجمع**: امزج نماذج من فئات مختلفة للمهام المعقدة.

4. **خصّص**: عدّل النماذج لتناسب سير عملك وأسلوبك.
